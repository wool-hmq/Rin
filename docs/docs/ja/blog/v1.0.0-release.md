# 二次創作版 v1.0.0：独立したバージョンラインの開始

**リリース日**: 2026年10月24日

本日より、羊角快車二次創作版（[wool-hmq/Rin](https://github.com/wool-hmq/Rin)）は独自のバージョンラインを運用し、公式アップストリーム（[openRin/Rin](https://github.com/openRin/Rin)）とは別に維持されます。本プロジェクトは標準的なセマンティックバージョニングに従い、最初のリリースは `v1.0.0`、リリースタグは `vX.Y.Z` を使用します。

## バージョンラインの規約

- バージョンは標準的なセマンティックバージョニング（`MAJOR.MINOR.PATCH`）に従い、専用ラインは `v1.0.0` から始まります
- リリースタグは常に `v` プレフィックスを使用します（`v1.0.0`）。プレリリースには `-beta` や `-rc.1` などのサフィックスを付けます（例：`v1.2.0-beta.1`）
- 項目が公式アップストリームと本プロジェクトのバージョンの両方に言及する場合、本プロジェクトのバージョンは区別のため `yjvX.Y.Z` と表記します
- 公式アップストリームの履歴（`v0.3.0`、`v0.2.0` など）は変更履歴に残り、公式アップストリームとしてラベル付けされます
- 両方のリポジトリが登場する場合、ドキュメントでは **二次創作版（本リポジトリ）** を先に、**公式アップストリーム openRin/Rin** を後に記載します
- 履歴の注記：以前のドキュメントで使用されていた `yjv1.0.0` ～ `yjv1.1.2` というラベルは、`v1.0.0` ～ `v1.1.2` と同じリリースです。変更されたのはプレフィックスのみです

## このリリースのハイライト

### 友だちリンクと検証

- メールによるセルフサービス友だちリンク：申請者はメールで友だちリンクの申請、変更、削除を行います。JSON テンプレート、画像キャプチャ、キャンセルコマンド、返信傍受のガイダンスが含まれます
- 友だちリンク検証は DNS TXT と HTML ファイルアップロードをサポートします。申請者はメールで `1` または `2` と返信し、DNS ルートは `_jiaofriend` ホストの TXT レコードを検証し、ファイルルートは厳格な 200 ステータスと `<body>` テキスト一致を維持します
- 友だちリンクのグループと表示順序、定期的な可用性チェック、`friends-sitemap.xml` の出力

### アカウントセキュリティ

- 全ユーザー向けの TOTP 二要素認証。リカバリーコードとログインレート制限を備え、パスワードなしのアカウントも対象
- 外部呼び出し用 API キー：管理者は設定ページからスコープ付き権限でキーを作成・失効できます
- ログインスロットリングとアカウントロックアウトは、パスワード / TOTP ログインパスに適用されます

### コンテンツと読書体験

- 複数のコメントシステム、Webhook 通知、RSS、動的な robots.txt を備えたサイトマップ
- AI 要約、AI 強化検索、カスタムモデル、並べ替え可能なフォールバックモデルキュー
- 共有 monorepo パッケージ（`@rin/api`、`@rin/ui`）とフロントエンド・バックエンド間の共有型

### デプロイとエンジニアリング

- デプロイ、開発、データベースのタスクを Rin CLI の下に統合し、GitHub Actions で Build / Deploy / Preview / Release / ドキュメントサイトのワークフローを提供
- Cloudflare Workers 向けに最適化された軽量バックエンドランタイム。ルートと依存関係はオンデマンドで読み込まれます
- 中国語と英語のドキュメントを並行して維持し、デプロイ、設定、データベースのガイドを現在の実装に合わせて調整

## アップグレードに関する注意

- 公式アップストリームから本エディションにアップグレードする場合、デプロイスクリプトが `server/sql/` 内のマイグレーションを自動的に適用します。手動の手順は不要です
- メールログイン、メール認証コード、セルフサービス友だちリンクはオプションであり、`EMAIL_SEND_URLS` / `EMAIL_SEND_KEYS` が必要です — [環境変数](../configuration/env) を参照してください
- TOTP、API キー、友だちリンクグループには追加の環境変数は不要です。必要に応じて管理ページから有効化してください

完全な変更リストは [変更履歴](../guide/changelog) に、デプロイ手順は [デプロイガイド](../guide/deploy) にあります。
