# はじめに

Rin（羊角快車二次創作版）は、Cloudflare Workers + D1 + R2 をベースにしたブログです。単一の Worker が静的フロントエンドアセットと API の両方を提供します。デプロイにサーバーは不要です。Cloudflare に解決されるドメイン名があればデプロイできます。本エディションは公式アップストリームの openRin/Rin をベースに、メールによるセルフサービス友だちリンク、TOTP、API キーを追加しています。

## デモ

[jiaoblog.dpdns.org](https://jiaoblog.dpdns.org)

## 機能

### アカウントとセキュリティ

1. GitHub OAuth ログインをサポート。デフォルトでは最初にログインしたユーザーが管理権限を持ち、それ以外のユーザーは一般ユーザーになります
2. Gitee OAuth ログインをサポート
3. QQ ログイン（心躍）をサポート
4. WeChat ログイン（聚合登録 / Mapay）をサポート
5. メール認証コードログインをサポート
6. ユーザー名/パスワードログインをサポート
7. 全ユーザー向けの TOTP 二要素認証をサポート。リカバリーコード付き
8. ログイン失敗をレート制限し、クレデンシャルスタッフィングを遅延させます

### コンテンツとインタラクション

9. 記事の執筆と編集をサポート
10. 任意の記事への変更/編集をローカルでリアルタイムに保存でき、複数の記事間で干渉しません
11. 自分だけに表示する設定をサポート。クラウド同期用の下書き箱として、またはよりプライベートな内容の記録として利用できます
12. 画像のドラッグ/ペーストアップロードを S3 プロトコル対応バケットにサポートし、リンクを生成します
13. 記事のエイリアス設定をサポートし、https://jiaoblog.dpdns.org/about のようなリンクで記事にアクセスできます
14. 記事をホームページの一覧に表示しないことをサポート
15. 記事へのコメント返信/コメント削除をサポート
16. Webhook によるコメント通知の送信をサポート
17. 記事内の最初の画像を自動識別し、記事一覧のヘッダー画像として表示することをサポート
18. 「#Blog #Cloudflare」のようなタグテキストを入力すると、自動的に解析して表示することをサポート

### 友だちリンク

19. 友だちのブログのリンク追加をサポート。バックエンドが 20 分ごとにリンクのアクセス可能状態を定期チェックして更新します
20. メールによるセルフサービス友だちリンクの申請、変更、削除をサポート。キャプチャとドメイン所有権検証付き
21. ドメイン所有権検証は DNS TXT レコードとアップロードした HTML ファイルの両方をサポート
22. 友だちリンクのグループと表示順序管理をサポート

### 統合と拡張性

23. スコープ付き権限で外部呼び出し用の API キーを発行することをサポート
24. AI 要約と AI 強化検索をサポート。カスタムモデルと設定可能なフォールバックモデル順序付き
25. RSS 出力とサイトマップ（友だちリンクのサイトマップを含む）をサポート
26. その他の機能については https://jiaoblog.dpdns.org を参照してください
