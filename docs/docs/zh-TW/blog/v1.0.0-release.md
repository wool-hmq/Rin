# 羊角快車二創版 v1.0.0 發布：獨立版本線啟動

**發布日期**: 2026年10月24日

從今天起，羊角快車二創版（[wool-hmq/Rin](https://github.com/wool-hmq/Rin)）啟用獨立版本線，與官方原版（[openRin/Rin](https://github.com/openRin/Rin)，上游）的版本線分開維護。本專案採用標準語意化版本，首個版本為 `v1.0.0`，發布標籤為 `vX.Y.Z`。

## 版本線約定

- 本專案版本號為標準語意化版本 `MAJOR.MINOR.PATCH`，獨立版本線從 `v1.0.0` 開始
- 發布標籤統一使用 `v` 前綴（`v1.0.0`）；預發布版本使用 `-beta`、`-rc.1` 等後綴，例如 `v1.2.0-beta.1`
- 同一條目同時涉及官方原版與本專案版本時，本專案版本寫作 `yjvX.Y.Z` 以示區分
- 官方原版的歷史發布記錄（`v0.3.0`、`v0.2.0` 等）繼續保留在更新日誌中，標註為官方原版/上游
- 文件中同時出現兩個儲存庫時，統一先列 **羊角快車二創版（本儲存庫）**，再列 **官方原版 openRin/Rin（上游）**
- 歷史說明：早期文件中的 `yjv1.0.0` ~ `yjv1.1.2` 編號即本版本線的 `v1.0.0` ~ `v1.1.2`，編號未變，僅統一為 `v` 前綴

## 本版本的主要內容

### 友鏈申請與驗證

- 郵件自助友鏈：訪客透過郵件完成友鏈申請、修改與刪除，流程包含 JSON 範本、人機驗證碼圖片、申請取消指令與回覆攔截引導
- 友鏈驗證支援 DNS TXT 與 HTML 檔案兩種方式：訪客在郵件中回覆 `1` 或 `2` 選擇驗證方式，DNS 方式透過 `_jiaofriend` 主機的 TXT 記錄驗證，檔案方式維持 200 狀態碼加 `<body>` 文字比對的嚴格驗證
- 友鏈分組與展示順序管理、友鏈可存取狀態排程檢查、`friends-sitemap.xml` 輸出

### 帳號安全

- TOTP 雙因素認證：所有使用者可用，支援復原碼與登入限流，無密碼帳號同樣可以啟用
- API Key 外部呼叫體系：管理員在後台建立、撤銷金鑰並限定權限範圍
- 登入限流與帳號鎖定策略在密碼 / TOTP 登入路徑上生效

### 內容與閱讀體驗

- 多套評論系統、Webhook 通知、RSS、Sitemap 與動態 robots.txt
- AI 摘要、AI 增強搜尋、自訂模型與回退模型佇列排序
- Monorepo 共享套件（`@rin/api`、`@rin/ui`）與前後端型別同步

### 部署與工程化

- 部署、開發、資料庫任務統一收斂到 Rin CLI，並搭配 GitHub Actions 的 Build / Deploy / Preview / Release / 文件站工作流程
- 後端執行環境面向 Cloudflare Workers 輕量化改造，路由與依賴按需載入
- 中英文文件隨儲存庫同步維護，部署指南、設定說明與資料庫結構文件依目前實作校準

## 升級提示

- 從官方原版升級到二創版時，部署腳本會自動執行 `server/sql/` 下的遷移腳本，無需手動操作
- 郵件登入、信箱驗證碼與郵件自助友鏈屬於選用功能，需要設定 `EMAIL_SEND_URLS` / `EMAIL_SEND_KEYS`，詳見 [環境變數說明](../configuration/env)
- TOTP、API Key、友鏈分組等功能無需額外環境變數，在後台頁面按需啟用即可

完整的版本改動記錄見 [更新日誌](../guide/changelog)，部署步驟見 [部署指南](../guide/deploy)。
