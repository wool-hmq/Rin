# 簡介

Rin（羊角快車二創版）是一套建構在 Cloudflare Workers + D1 + R2 全家桶之上的部落格，前端靜態資源與 API 由同一個 Worker 提供，只要一個解析到 Cloudflare 的網域就能部署。本版基於官方原版 openRin/Rin（上游）二次開發，並加入電子郵件自助友連、TOTP、API Key 等能力。

## 示範網址

[jiaoblog.dpdns.org](https://jiaoblog.dpdns.org)


## 特色

### 帳號與安全

1. 支援 Github OAuth 登入，預設第一個登入的使用者擁有管理權限，其他使用者皆為一般使用者
2. 支援 Gitee OAuth 登入
3. 支援 QQ 登入（心月互聯）
4. 支援微信登入（聚合登入）
5. 支援電子郵件驗證碼登入
6. 支援帳號密碼登入
7. 支援 TOTP 雙因素驗證，全體使用者皆可使用，並提供復原碼
8. 登入失敗限流，降低撞庫風險

### 內容與互動

9. 支援文章的撰寫與編輯
10. 支援在本地即時儲存任意文章的修改／編輯，且多篇文章互不干擾
11. 支援設定為僅自己可見，可當作雲端同步的草稿箱或記錄隱私性較強的內容
12. 支援以拖曳／貼上方式上傳圖片到支援 S3 協定的儲存桶並產生連結
13. 支援設定文章別名，可透過類似 https://jiaoblog.dpdns.org/about 的連結存取文章
14. 支援文章不列出於首頁列表中
15. 支援回覆評論文章／刪除評論
16. 支援透過 Webhook 寄送評論通知
17. 支援自動辨識文章中的第一張圖片，並作為頭圖顯示於文章列表中
18. 支援輸入類似「#部落格 #部署 #Cloudflare」的標籤文字並自動解析為標籤

### 友連

19. 支援新增友連，同時後端每隔 20 分鐘定期檢查更新友連的可存取狀態
20. 支援透過電子郵件自助申請／修改／刪除友連，流程包含人機驗證與網域所有權驗證
21. 網域所有權驗證支援 DNS TXT 記錄與上傳 HTML 檔案兩種方式
22. 支援友連分組與顯示順序管理

### 整合與開放

23. 支援為外部呼叫簽發 API Key，並限定權限範圍
24. 支援 AI 摘要與 AI 增強搜尋，可自訂模型與回退模型的順序
25. 支援 RSS 輸出與網站地圖（含友連網站地圖）
26. 更多特色請參考 https://jiaoblog.dpdns.org
