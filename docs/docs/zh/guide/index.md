# 简介

Rin（羊角快车二创版）是一个基于 Cloudflare Workers + D1 + R2 全家桶的博客，前端静态资源与 API 由同一个 Worker 提供，只需要一个解析到 Cloudflare 的域名即可部署。本版基于官方原版 openRin/Rin（上游）二次开发，并加入邮箱自助友链、TOTP、API Key 等能力。

## 演示地址

[jiaoblog.dpdns.org](https://jiaoblog.dpdns.org)


## 特性

### 账号与安全

1. 支持 Github OAuth 登录，默认第一个登录的用户拥有管理权限，其他用户均为普通用户
2. 支持 Gitee OAuth 登录
3. 支持 QQ 登录（心月互联）
4. 支持微信登录（聚合登录）
5. 支持邮箱验证码登录
6. 支持账号密码登录
7. 支持 TOTP 双因素认证，全体用户可用，并提供恢复码
8. 登录失败限流，降低撞库风险

### 内容与互动

9. 支持文章的写作与编辑
10. 支持本地实时保存对任意文章的修改/编辑且多篇文章互不干扰
11. 支持设置为仅自己可见，可以充当云端同步的草稿箱或者记录隐私性较强的内容
12. 支持拖拽/粘贴上传图片到支持 S3 协议的存储桶并生成链接
13. 支持设置文章别名，可通过形如 https://jiaoblog.dpdns.org/about 链接访问文章
14. 支持文章不列出在首页列表中
15. 支持回复评论文章/删除评论
16. 支持通过 Webhook 发送评论通知
17. 支持自动识别文章中的第一张图片并作为头图展示在文章列表中
18. 支持输入形如"#博客 #部署 #Cloudflare"之类的标签文本并自动解析为标签

### 友链

19. 支持添加友链，同时后端每间隔 20 分钟定期检查更新友链可访问状态
20. 支持通过邮件自助申请 / 修改 / 删除友链，流程包含人机验证与域名所有权验证
21. 域名所有权验证支持 DNS TXT 记录与上传 HTML 文件两种方式
22. 支持友链分组与展示顺序管理

### 集成与开放

23. 支持为外部调用签发 API Key，并限定权限范围
24. 支持 AI 摘要与 AI 增强搜索，可自定义模型与回退模型顺序
25. 支持 RSS 输出与站点地图（含友链站点地图）
26. 更多特性请参考 https://jiaoblog.dpdns.org
